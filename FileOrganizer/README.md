Python FileOrganizer
Автоматичне сортування файлів за типами за допомогою Python.

Можливості
Початкове сортування файлів.
Автоматичне виявлення нових файлів у реальному часі.
Сортування за категоріями.
Збереження оригінальних назв файлів.
Захист від перезапису файлів з однаковими назвами.
Обробка помилок під час переміщення.

Категорії файлів
Images — зображення.
Documents — документи.
Music — аудіофайли.
Videos — відеофайли.
Archives — архіви.
Programming — файли програмного коду.
Programs — виконувані файли та сценарії.
Other — інші формати.

Технології
Python
pathlib
shutil
time

Як запустити
1. Встановіть Python.
2. Завантажте або клонуйте репозиторій.
3. Відкрийте папку проєкту.
4. Запустіть команду:
   python main.py
5. Додавайте файли до папки TestFiles.
6. Для завершення роботи натисніть Ctrl+C у терміналі.

Обмеження
Програма стежить за файлами безпосередньо в папці TestFiles.
Вона працює, поки запущений скрипт Python.
Нерозпізнані формати переміщуються до папки Other.
